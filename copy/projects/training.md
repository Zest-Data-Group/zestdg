## Workshops

- **R for spatial data** — Software Carpentry-style lessons developed for NASA DEVELOP participants.
- **Google Earth Engine for ecologists** — a one-day introduction for the Geospatial Centroid (materials: https://github.com/dcarver1/geeForEcologist).
- **Introduction to arcpy** — Python automation for ArcGIS users (materials: https://github.com/dcarver1/introToArcpy).

## Approach

Every workshop is built around a real dataset and a real question, with all materials published openly so participants can keep working after the session ends.
